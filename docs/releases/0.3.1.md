# TL;PR 0.3.1

## Changes

- Show a chevron-only fold toggle in React comment and issue body headers. The full label stays available to assistive technologies, and GitHub's “Last edited by” history keeps its room instead of being clipped in narrow columns
- Keep the labelled toggle in classic headers and in the Overview description bar

## Live Overview validation

The 0.3.0 controller ran on a live pull request Overview page with an opted-in account (2026-11-07):

- The page matched the reconstructed structure: `#overview-comments` section, Description section, status pane, `timeline-item` wrappers, `article#issuecomment-…` comments with React headers, and no classic container
- The view was detected as Overview, with the description and six comments enhanced and one reading rail at the top of the column
- The newest-first list was detected from timestamps: the three newest and two oldest items stayed visible while three middle items folded
- Expanding, collapsing, the timeline summary and persistence under `gh-pr-comment-collapse:v3` worked with canonical comment anchors, and the controller stayed at one scan while idle
- A real “🧾 Proposed merge commit” comment rendered by GitHub was parsed into its subject and body, and the React pull request title was read

The live run used a test build with the merge helper stubbed and locale catalogs reduced to English; the merge confirmation form was not opened on a real pull request. Installing the packaged extension in a Chrome profile remains a manual step.
