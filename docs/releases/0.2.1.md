# TL;PR 0.2.1

## Changes

- Restore responsive comment toggles when GitHub caches a hidden edit form or replaces comment controls, including the last comment in a conversation
- Resume enhancement when an active editor closes through a visibility attribute change
- Restore toolbar and timeline controls after GitHub clones a cached conversation
- Read current React PR titles and highlighted Markdown blocks
- Add an explicit **Insert** button to the merge confirmation form when the optional helper is enabled
- Fill only the extended description: PR title, one blank line, then the designated comment’s code block
- Preserve the default merge commit title and manually edited descriptions, including deliberately blank text
- Require source selection and preview when several comments qualify, and reject stale forms or unrelated code sections
- Keep the helper off by default, with no new permissions, network requests, automatic submission or merge action

- Preserve temporary direct-link expansion when GitHub replaces the comment header or body, while honoring subsequent manual collapse
- Preserve independent manual comment and timeline choices across same-URL navigation and cloned anchor targets
- Observe in-place text hydration and avoid idle scan loops when all middle timeline items are being edited
- Keep active editors visible when a crowded timeline is folded
- Detect replacement timeline nodes even when their identifiers are unchanged
- Re-evaluate automatic folding after content hydration or image loading while preserving explicit choices and direct links
- Release listeners from detached comment bodies and avoid quadratic timeline containment checks
- Keep controls responsive when site storage is unavailable and merge independent preference changes from other tabs

- Start safely after same-document navigation from a GitHub repository or list, using a navigation-only bootstrap outside supported numeric conversations
- Load styles and conversation settings only inside supported conversations; remove active effects on departure

## Verification

179 automated tests pass, including ten simulated reloads with repeated last-comment toggles, asynchronous editor and body replacement, cloned controls and manual-edit retention. Formatting, lint, TypeScript, build and package validation also pass.

Fixtures retain the current rendered GitHub structures inspected earlier, with project content and author details sanitized. Native Chromium source-fixture checks verified folding, editor visibility, in-place text hydration, DOM replacement and explicit merge-description insertion with manual-edit preservation and zero submissions. This does not establish live GitHub React retention or installed-extension behavior: cloud browser policy explicitly rejects unpacked extension installation, and that refusal was respected. No live merge fields were edited and no merge was submitted. The regression suite also covers navigation-only bootstrap boundaries, active editors, same-ID replacement, image loads, detached listener cleanup, storage quota failures and cross-tab preference preservation.
