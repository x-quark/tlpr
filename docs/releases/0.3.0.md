# TL;PR 0.3.0

## GitHub views

- Support the new pull request **Overview** page (GitHub public preview, 2026-11-05) alongside the classic conversation: long comments, the description and the middle of the comment list fold as before
- Keep the two oldest and three newest items when GitHub lists the newest comments first, and follow the order when the sort changes
- Restore React issue pages, whose comment anchors now live on the header
- Detect the view automatically; the popup can pin **Classic** or **Overview** if detection ever fails
- Add a one-click link from the Overview to the classic view of the same pull request, and back from `?overview=false`
- Share folding preferences across views through canonical comment anchors

## Merge message helper

- Read the proposals posted in conversations: “🧾 Proposed merge commit” with a ` ```git ` block, a lone ` ```git ` comment, or the earlier “🧾 Merge commit body” template
- Fill **Commit message** with the subject and **Extended description** with the body of a complete message; body-only templates keep GitHub's title under the pull request title
- Read the current React pull request title
- Work in merge, squash and rebase forms, inline or in the Overview confirmation dialog
- Preselect the latest proposal, keep earlier ones selectable, and show the exact title, description and source comment before insertion
- Ask before replacing typed text and offer **Undo**; still never submit, merge, fetch or store anything

## Fixes and quality

- Leave GitHub App comments untouched again: authors now render with a “Bot” label instead of a `[bot]` suffix
- Measure comments before painting to avoid repeated layouts on long conversations, and skip scans for page changes outside the conversation
- Refresh the popup with a light theme and a GitHub view selector; restyle the inline merge panel
- Add V8 coverage with regression thresholds to `pnpm check`

## Verification

`pnpm check` passes locally: focus rules, formatting, lint, strict TypeScript, the Vitest suite with coverage thresholds, build, package and package validation. Diagnostic probes of the detection code ran on public pages: a classic pull request with a GitHub Actions comment and a React issue with a bot comment. The Overview needs an opted-in GitHub account; its fixture is reconstructed from GitHub's public page bundle captured on 2026-11-07 and has not been exercised on a live Overview page. Installing the unpacked extension in a real Chrome profile remains a manual step.
